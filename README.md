## 🚀 Featured Projects

### [🧬 BioData Copilot](https://github.com/HaneefaShaikGit/biodata-copilot)

**Python · Pandas · DuckDB · SQL · cBioPortal · OpenAI · Streamlit**

A biomedical analytics project combining **data engineering, cancer genomics, deterministic SQL analytics, and grounded AI explanations**.

- Retrieves public breast-cancer clinical and mutation data from the **cBioPortal REST API**
- Preserves raw source data and transforms semi-structured biomedical records into analytical datasets
- Models patient, sample, and mutation data in **DuckDB**
- Uses reviewed SQL for subtype, mutation, mutation-burden, and data-quality analysis
- Separates analytical computation from AI explanation: **SQL calculates the facts; AI explains the verified result**
- Includes automated data-quality tests and explicit handling of table grain, missingness, and analytical denominators
- Explores a future research direction around **provenance-aware and trustworthy biomedical AI**
